**「人提供一个想法，AI 交付产品，没有人参与。」** 九篇读完，概念容易散在脑子里。这篇只做一件事：把这句话逐字压实，收成一张概念 → 机理 → 方法论的闭环地图——每篇各归其位，互为支撑；想深入哪一层，按图索骥即可。

## 为什么值得看

“AI 能不能自己把产品做出来”这个问题，多数讨论停在感觉层面——“基本能自动”“关键处留个人把关”。这个系列给出相反的答案：**没有人参与**——并把这句话写成一份**可逐条检验的契约**，再用工程纪律把它撑起来。

九篇分别钻进了契约、机件与方法论的细节。代价是：单篇越深，全景越容易丢。本篇不重复任何一篇的论证，只交付两样东西——**一句可检验的核心概念**，和一张 **“想解决什么问题该看哪篇”的闭环地图**。

## 你将学到三点

1. **“人提供一个想法，AI 交付产品，没有人参与”是一句可检验的契约**，不是百分比式的口号：四条主张，每条都逼着具体机件必须存在。
2. **概念、机理、方法论三层是闭环**：概念定契约，机理兑现契约，方法论防止契约腐化——缺任何一层，另外两层都撑不住。
3. **九篇各有唯一职责**：按自己当前的问题（这是什么 / 怎么运转 / 该信奉什么）选入口，不必线性读完。

## 核心概念：一句话与四条主张

整个系列只讲一句话：

> **人提供一个想法，AI 交付产品，没有人参与。**

这句话的每一个词都取字面义：**人提供一个想法**——人只做这一个动作（建项目、写下想法），此后不再出现在交付链路里；**AI 交付产品**——需求、设计、开发、测试、发布、运营全部由 AI 角色团队完成，一路送到生产；**没有人参与**——交付环内没有任何人工环节：没有审批门，没有“关键处把关”，不为人类阻塞。

听起来像口号，所以它被拆成四条可以证伪的主张——这也是「人不在环内」一词的精确含义：

| 主张 | 它禁止了什么 |
|---|---|
| **一个动作启动一切** | 禁止“人还要写第一条任务”——项目一建，kickoff 任务自动生成；此后每条任务都由 Agent 撰写、派发、认领、执行、评审 |
| **没有审批门** | 禁止 PRD 签字、发布 go/no-go、人工回滚决策——质量只能由机器关卡执行 |
| **不为人类阻塞** | 禁止把通知通道当审批——通知是升级路径，记录后继续或干净停止，从不等待回复 |
| **人在系统之上，不在系统之内** | 禁止人逐任务踩刹车——人的固定工作是元评审：读治理报告，改进系统本身 |

它同时也不是三样东西：不是聊天机器人，不是代码生成器，不是有人盯着的流水线。它是一个**自主交付组织**——组织图、运行手册、审计轨迹全部住在 git 里。

四条主张的完整论证与五条禁令，见系列第一篇《人不在环内：一个 AI 自主交付组织的概念契约》。

## 三层如何互锁

地图上任何一层都能单独做，真正让三层咬合的是下面四条不变式。它们在九篇里反复出现，在这里集中小结：

1. **每删掉一道人工关卡，必须长出一道机器关卡。** 逐交付物评审、集成面评审门、端到端测试是契约的价签；砍掉它们，自主性只是以机器速度放大错误。
2. **周期性工作的所有权永远在中心。** 角色可以多实例，但触发权只属于调度器——谁自己排班，谁就重复产出。
3. **文档是可执行资产，不是参考资料。** 下游 Agent 逐字执行它：歧义会被按字面实现，占位符会被真的运行。
4. **人的介入换层级，而不是换一句“更少介入”。** 人读的是报告，不是请求；产出的是对系统的改进，不是对任务的批准。

## 如何使用这个系列

九篇独立成文，不必线性读完。按你当前的问题选入口：

- **想先弄懂“这是什么、凭什么成立”** → 概念层三篇，从《人不在环内：一个 AI 自主交付组织的概念契约》开始。
- **想知道“它到底怎么运转”** → 机理层三篇，从《十三个阶段与它们的工件：Agent 之间的类型系统》入手，调度细节看《无人值守调度的三件机件：认领锁、中心推送、幂等键》。
- **想借鉴“背后信奉的工程方法”** → 《文档即可执行资产：当 Agent 逐字消费你的规格》与《人在系统之上：每周治理报告与元评审工作法》，最后用《一个想法进，一个产品出：九类 AI Agent 运转中的完整软件公司》把所有概念串成一次真实运转。

对哪一层感兴趣，上面表格里的标题就是入口——九篇已全部发布，漏读或错过的按标题检索即可补上，想读哪篇就找哪篇。

## 总结

1. **“人提供一个想法，AI 交付产品，没有人参与”是一句可检验的契约**——一个动作启动一切、无审批门、不为人类阻塞、人在系统之上，四条主张各有机件支撑。
2. **三层闭环缺一不可**：概念定契约、机理兑现契约、方法论防腐化，九篇各归其位。
3. **从你最缺的那一层读起**：不必九篇全读，用地图找到当前问题的入口即可。

概念已经铺完。最小的第一步，是把你自己的系统里“此刻正在等人回复”的那一段找出来，写成一条主张——然后按图索骥，看哪一篇讲的正是它。
